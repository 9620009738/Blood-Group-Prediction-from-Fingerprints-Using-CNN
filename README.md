# Blood-Group-Prediction-from-Fingerprints-Using-CNN# 🩸 Blood Group Prediction from Fingerprints Using CNN

A deep learning-based web application that predicts a person's blood group from fingerprint images using a Convolutional Neural Network (CNN).

## 📌 Project Overview

This project explores the use of **computer vision and deep learning** for fingerprint-based blood group classification.

The application allows a user to provide a fingerprint image, processes the image using the trained CNN model, and generates a predicted blood group through a Flask-based web application.

> **Note:** This project is intended for academic and research purposes. Fingerprint-based blood group prediction should not be considered a substitute for clinically validated blood-group testing.

## 🎯 Objectives

- Develop a CNN-based image classification system.
- Process fingerprint images for blood-group prediction.
- Build a simple web interface for image-based prediction.
- Integrate the trained machine-learning model with a Flask application.
- Explore the application of deep learning in biometric image analysis.

## ⚙️ How It Works

The system follows a basic image-classification pipeline:

```text
Fingerprint Image
       ↓
Image Preprocessing
       ↓
CNN Feature Extraction
       ↓
Feature Learning
       ↓
Blood Group Classification
       ↓
Predicted Blood Group
```

### 1. Image Input

The user provides a fingerprint image through the web application.

### 2. Preprocessing

The input image is prepared for the CNN model through image processing and normalization.

### 3. CNN Prediction

The processed fingerprint image is passed to the trained CNN model, which extracts image features and performs classification.

### 4. Result

The application displays the predicted blood-group class to the user.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/9620009738/Blood-Group-Prediction-from-Fingerprints-Using-CNN.git
```

Navigate to the project:

```bash
cd Blood-Group-Prediction-from-Fingerprints-Using-CNN
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Start the Flask application:

```bash
python app.py
```

Then open the local URL displayed by Flask in your browser.

## 📊 Dataset

The project contains fingerprint image data organized for the blood-group classification task.

The dataset is used for training/testing the CNN model and evaluating the image-classification workflow.

## 🔬 Model

The core prediction component uses a **Convolutional Neural Network (CNN)**.

CNNs are suitable for image-classification tasks because they can automatically learn spatial features such as edges, textures, shapes, and higher-level patterns from images.
